# PiterFM

**Неофициальный Windows-плеер для прослушивания Питер FM 100.9.**

PiterFM — небольшое настольное приложение для Windows, которое воспроизводит онлайн-эфир радиостанции, показывает текущую композицию, обложку и историю недавно прозвучавших треков.

> **Важно:** PiterFM — независимый неофициальный проект. Он не является официальным приложением радиостанции «Питер FM» и не аффилирован с владельцами радиостанции или правообладателями её бренда.

## Возможности

- прямой эфир **Питер FM 100.9**;
- отдельное Windows-приложение — без браузера;
- кнопки запуска и остановки эфира;
- регулировка громкости;
- отображение **исполнителя и текущей композиции**;
- автоматический поиск обложки трека;
- список недавно прозвучавших композиций;
- автоматическое обновление метаданных;
- тёмный интерфейс с оранжевыми акцентами;
- встроенная иконка приложения;
- блок поддержки автора **OlegKrs**.

## Системные требования

- Windows 10 или Windows 11 x64;
- подключение к интернету;
- системные мультимедийные компоненты Windows.

Для воспроизведения используется системный медиадвижок Windows. Если приложение сообщает об отсутствии Windows Media Player Legacy, включите его в **Параметры Windows → Дополнительные компоненты**.

## Запуск

1. Скачайте `PiterFM_v1.0.0.exe` из Releases.
2. Запустите файл двойным щелчком.
3. Нажмите **«СЛУШАТЬ»**.
4. Через несколько секунд появится звук, а блок текущего трека обновится автоматически.

Установка не требуется.

## SmartScreen и цифровая подпись

Пока публичный EXE не подписан доверенным Authenticode-сертификатом, Windows SmartScreen может показывать предупреждение о неизвестном издателе.

Это само по себе не означает, что файл вредоносный. Для публичных релизов рекомендуется подписывать EXE цифровой подписью. Подробная инструкция находится в [`SIGNING.md`](SIGNING.md).

Для каждого релиза также публикуется SHA-256-хеш файла.

## Откуда приложение получает данные

Воспроизведение и информация об эфире запрашиваются из доступных онлайн-источников. Для определения актуального трека приложение может сравнивать несколько публичных источников метаданных. Обложка композиции подбирается отдельно по найденным исполнителю и названию.

Из-за особенностей онлайн-радио информация о текущей песне иногда может появляться с небольшой задержкой.

## Конфиденциальность

PiterFM не требует регистрации и не содержит собственной системы аккаунтов.

В текущей версии нет встроенной пользовательской аналитики или собственной телеметрии. Для своей работы приложение делает сетевые запросы к радиопотоку и сервисам, необходимым для получения метаданных и обложек. Подробнее: [`PRIVACY.md`](PRIVACY.md).

## Сообщить об ошибке

Если радио играет, но метаданные отображаются неправильно, при создании Issue желательно указать:

- версию PiterFM;
- версию Windows;
- что отображается в блоке «Сейчас играет»;
- что находится в списке «Недавно в эфире»;
- скриншот окна программы.

Используйте шаблон **Bug report** в разделе Issues.
