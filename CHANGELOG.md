# Changelog

Все заметные изменения публичных версий PiterFM будут перечисляться в этом файле.

## [1.0.1] — 2026-09-14

Исправление отображения текущей композиции.

### Исправлено

- восстановлено отображение **названия песни** в блоке «Сейчас играет»;
- обновлён разбор данных Volna.top после изменения структуры страницы;
- сохранено отдельное отображение исполнителя и названия композиции;
- сохранены история эфира, обложки, интерфейс, встроенная иконка и блок автора.

## [1.0.0] — 2026-09-07

Первый публичный релиз.

### Добавлено

- воспроизведение онлайн-эфира Питер FM 100.9;
- самостоятельный Windows x64 EXE;
- интерфейс без браузера и PowerShell;
- кнопки «СЛУШАТЬ / СТОП»;
- кастомный регулятор громкости;
- блок «Сейчас играет»;
- отображение исполнителя и названия композиции;
- поиск обложки текущего трека;
- список недавно прозвучавших композиций;
- автоматическое обновление метаданных;
- выбор свежего источника метаданных;
- фильтрация служебных HTML-значений;
- фирменная иконка EXE;
- подпись `by OlegKrs`;
- блок поддержки автора.
