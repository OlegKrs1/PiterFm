# Цифровая подпись PiterFM

Для публичного распространения Windows-программы лучше подписывать каждый релиз Authenticode-сертификатом.

## Что даёт подпись

После подписания пользователь может открыть:

**PiterFM.exe → Свойства → Цифровые подписи**

и проверить издателя и целостность файла.

Подпись также снижает количество предупреждений Windows о неизвестном издателе, хотя SmartScreen-репутация формируется отдельно и может потребовать времени.

## Что понадобится

1. Code Signing certificate от доверенного удостоверяющего центра или облачного сервиса подписи.
2. Windows SDK.
3. `signtool.exe`.

Не используйте самоподписанный сертификат для публичных релизов — на чужих компьютерах он по умолчанию не считается доверенным.

## Подписание

Если сертификат установлен и Signtool может выбрать его автоматически:

```bat
signtool sign /fd SHA256 /tr YOUR_TIMESTAMP_SERVER /td SHA256 /a PiterFM_v1.0.0.exe
```

Где:

- `/fd SHA256` — алгоритм подписи файла;
- `/tr` — RFC 3161 timestamp-сервер вашего удостоверяющего центра;
- `/td SHA256` — алгоритм timestamp;
- `/a` — автоматический выбор подходящего сертификата.

Используйте timestamp-сервер, который рекомендует именно ваш поставщик сертификата.

## Проверка подписи

```bat
signtool verify /pa /v PiterFM_v1.0.0.exe
```

После успешной проверки Signtool должен сообщить, что файл успешно проверен.

## Порядок подготовки релиза

1. Собрать окончательный EXE.
2. Проверить его локально.
3. Подписать EXE.
4. Проверить подпись через `signtool verify`.
5. **Только после подписи** посчитать SHA-256.
6. Создать ZIP.
7. Загрузить EXE, ZIP и `SHA256SUMS.txt` в GitHub Release.

Нельзя изменять EXE после подписания: любое изменение файла делает подпись недействительной.

## SHA-256 в PowerShell

```powershell
Get-FileHash .\PiterFM_v1.0.0.exe -Algorithm SHA256
```

## Имя издателя

Надпись `by OlegKrs` внутри приложения не определяет имя, которое Windows показывает как проверенного издателя.

Имя издателя берётся из сертификата и должно соответствовать данным, подтверждённым удостоверяющим центром.
