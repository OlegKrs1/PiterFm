# PiterFM v1.0.1 — исправление названия текущей песни

Небольшое исправление неофициального Windows-плеера для Питер FM 100.9.

### Что исправлено

- исправлено получение названия текущей композиции;
- обновлён разбор данных источника Volna.top после изменения структуры страницы;
- исполнитель и название песни снова отображаются отдельно;
- сохранены история эфира и поиск обложек.

### Что не изменилось

Интерфейс, кнопки управления, регулятор громкости, встроенная иконка, подпись `by OlegKrs` и блок поддержки автора остались без изменений.

### Требования

Windows 10/11 x64 и подключение к интернету.

Установка не нужна — достаточно скачать и запустить `PiterFM_v1.0.1.exe`.

### Проверка файла

SHA-256 опубликован в `SHA256SUMS.txt`.

### Важно

PiterFM — независимое **неофициальное** приложение и не связано с владельцами радиостанции «Питер FM».

Если Windows SmartScreen предупреждает о неизвестном издателе, это может быть связано с отсутствием доверенной Authenticode-подписи у релиза.
