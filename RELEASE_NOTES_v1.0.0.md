# PiterFM v1.0.0 — первый публичный релиз

Первая публичная версия неофициального Windows-плеера для Питер FM 100.9.

### Что умеет

- слушать прямой эфир в отдельном приложении;
- показывать текущего исполнителя и название песни;
- автоматически подбирать обложку;
- показывать последние прозвучавшие треки;
- обновлять информацию об эфире автоматически;
- регулировать громкость через фирменный слайдер.

### Требования

Windows 10/11 x64 и подключение к интернету.

Установка не нужна — достаточно скачать и запустить `PiterFM_v1.0.0.exe`.

### Проверка файла

SHA-256 опубликован в `SHA256SUMS.txt`.

### Важно

PiterFM — независимое **неофициальное** приложение и не связано с владельцами радиостанции «Питер FM».

Если Windows SmartScreen предупреждает о неизвестном издателе, это связано с отсутствием коммерческой Authenticode-подписи у этого релиза.
